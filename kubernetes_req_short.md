<h1>[ДРАФТ] Требования ИБ к подсистеме контейнерной оркестрации</h1>

ПКО — Подсистема контейнерной оркестрации

ТУЗ — Техническая учетная запись

POD — минимальная единица развертывания в Kubernetes, группа из одного или нескольких контейнеров, которые имеют общие ресурсы (сеть, хранилище) и запускаются на одном узле

Frontend node — узел, предназначенный для обслуживания входящего и исходящего трафика. Компоненты предоставляющие доступ к сервисам запущенным на основе ПКО

System node — выделенный узел для размещения служебных компонентов (мониторинг, логи, DNS), чтобы изолировать их от пользовательских нагрузок

Master node  — узел, на котором запущены компоненты Control Plane (API Server, etcd, scheduler), управляющие кластером.

Worker node — рабочий узел, предназначенный для выполнения пользовательских приложений и рабочих нагрузок.

IdP — Identity Provider сервис, который отвечает за управление учетными записями пользователей и аутентификацию

PAM — Privileged Access Management, решение для контроля доступа привилегированных пользователей

ДЭСЗИ — Департамент Экспертизы и Сервисов Защиты Информации

| 8.37 | При организации постоянного хранения (PV) данных для сервисов запущенных на базе ПКО запрещено использовать тома использующие ресурсы узлов ПКО. Необходимо использовать динамическое выделение томов с изоляцией данных каждого сервиса.                                                                                                                                                                                                                     |                                                                                                                                                                                                                                                                                                                               |
| 8.38 | При организации постоянного хранения (PV) данных для сервисов запущенных на базе ПКО необходимо настроить отдельный StorageClass для каждого арендатора для повышения изоляции. | 8.39 | В случае, если POD объединяет несколько контейнеров, необходимо настроить монтирование тома или переменные окружения так, чтобы только необходимому контейнеру предоставлялся доступ к секрету.                                                                                                                                                                                                                                                                                                    |                                                                                                                                                                                                                                                                                                                               |
